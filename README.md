# Download R and RStudio

A small, single-page guide with official download links for:

- R for Windows, macOS, and Linux
- RStudio Desktop for Windows, macOS, and Linux

The page is intended to help BIOSZEN users install R first and then RStudio Desktop.

Social-sharing previews use the Open Graph metadata in `index.html` and the 1200 × 630 `og-preview.png` image.

## View locally

Open `index.html` in a web browser. No build step or dependencies are required.

## Publish with GitHub Pages

The site is compatible with GitHub Pages directly from the repository root on the `main` branch.

## Updating the page

Edit `index.html`. Keep the links pointed at the official CRAN and Posit download pages so they continue to direct users to current stable releases.
